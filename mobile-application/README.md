# Mobile Application — Flutter (تطبيق الموبايل للعملاء)

## 📌 الوصف والغرض (What this folder does)
هذا الفولدر مخصص بالكامل **لمطور تطبيقات الموبايل (Flutter Mobile Developer)**.
يحتوي على تطبيق الأندرويد والـ iOS واللينكس المكتوب بفريمورك **Flutter**.

## 🌟 الميزات المطبقة (Implemented Features)
1. **أيقونة الشات بوت في أسفل يسار الشاشة (Bottom-Left Chatbot)**:
   - زر عائم مخصص في الركن السفلي الأيسر يفتح المساعد الذكي للتسوق الصوتي وبناء سلات التوفير (1-365 يوم) وإرسال إشادات وملاحظات العملاء إلى **`cyborgcoding1@gmail.com`**.
2. **إلغاء الطلبات واسترجاع المخزون (Order Cancellation)**:
   - إمكانية إلغاء الطلبات من شاشة "طلباتي" (My Orders) مع رسالة تأكيد واسترجاع كميات المنتجات تلقائياً إلى مخزون السوبرماركت فور الإلغاء.
3. **الدعم الثنائي للغة (عربي / English)**:
   - زر تبديل اللغة في شريط التطبيق العلوي مع دعم كامل للاتجاه من اليمين لليسار (`TextDirection.rtl`) وترجمة فورية لكل الشاشات.
4. **الوضع الليلي والنهاري (Dark Mode & Light Mode)**:
   - ثيم نهاري فاقع وعالي الوضوح وثيم ليلي سيبراني أنيق مع أسعار خضراء زاهية (`#22C55E`).
5. **شكل بطاقات المنتجات (features/data-1 format)**:
   - صورة المنتج عالية الجودة، الاسم بالعربية والإنجليزية، السعر الأخضر الزمردي، واستيكر الباركود Code-128.

## 🏛️ البنية المعمارية (MVC Architecture)
- **`lib/models/`**:
  - `product.dart`: نموذج المنتج وبيانات الباركود والمخزون.
  - `cart_item.dart`: نموذج عنصر سلة المشتريات.
  - `order.dart`: نموذج الطلب وحالة الإلغاء.
- **`lib/controllers/`**:
  - `catalog_controller.dart`: إدارة الكتالوج والبحث والتصفية.
  - `cart_controller.dart`: حساب الإجمالي مع ضريبة 14% وإتمام الدفع.
  - `orders_controller.dart`: جلب الطلبات وتنفيذ طلب الإلغاء عبر API.
  - `chatbot_controller.dart`: معالجة الذكاء الاصطناعي وبناء السلة وإرسال الإيميلات.
  - `theme_controller.dart`: إدارة الثيمات الفاتحة والداكنة.
  - `language_controller.dart`: إدارة اللغات والقواميس والـ RTL.
  - `api_config.dart`: عنوان الـ API الديناميكي (المحاكي / الجهاز الحقيقي / اللينكس).
- **`lib/views/`**:
  - `home_view.dart`: الشاشة الرئيسية وزر الشات بوت في أسفل اليسار.
  - `tabs/`: شاشات (المتجر، السلة، المؤونة الذكية، وسجل الطلبات).
  - `widgets/`: بطاقة المنتج وبار كود ستيكر.
  - `chatbot/`: واجهة المساعد الذكي وإرسال الملاحظات.

## 🚀 كيفية التشغيل (How to Run)
```bash
# الانتقال لفولدر الموبايل:
cd mobile-application

# تثبيت الحزم:
flutter pub get

# تشغيل التطبيق على Linux:
flutter run -d linux

# تشغيل التطبيق على محاكي Android:
flutter run -d emulator
```
